# MIDIS Prompt Builder (Beta)

Интерактивный конструктор учебных и профессиональных промптов для студентов Международного института дизайна и сервиса (МИДиС, Челябинск).

Сервис помогает студентам колледжа и института составлять точные и контекстные запросы к нейросетям (ChatGPT, Claude, DeepSeek, Gemini и др.) с учетом специальности, курса, уровня подготовки, дедлайнов и ресурсов института.

## Возможности

- 24 сценария под учебные, проектные и карьерные задачи:
  - Учеба и сессия: индивидуальный план обучения, подготовка к защите и экзаменам, конспекты лекций, тесты для самопроверки, экстренная подготовка к зачету за 24 часа.
  - Проекты и практика: генератор идей, оформление кейсов, тексты для интерфейсов, стиль и айдентика бренда, путь пользователя в приложении.
  - Карьера и старт: тренировка перед собеседованием, план перехода в смежную профессию, поиск стажировок, расчет сметы проектов, профессиональный английский, полезные знакомства.
  - Навыки и командная работа: поиск и исправление сложных ошибок, разбор кода и макетов, решение разногласий в команде, запросы к нейросетям для генерации арта и ассетов.
- Полный каталог специальностей МИДиС: все направления высшего образования (бакалавриат) и среднего профессионального образования (колледж).
- Динамическая калибровка контекста: учет курса, срока до окончания обучения, формы обучения (очная/заочная) и реального практического опыта без шаблонных противоречий.
- Без сторонних зависимостей: чистый стек HTML5, CSS3 и Vanilla JavaScript (ES6+), сборка и сторонние библиотеки не требуются.
- Адаптивный интерфейс: поддержка светлой и темной темы, адаптивная верстка под смартфоны, планшеты и мониторы.

## Запуск проекта

Для локального запуска не требуются Node.js или менеджеры пакетов:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/whywace/midis-prompt-builder-beta.git
   ```
2. Откройте файл `index.html` в любом браузере.

## Публикация на GitHub Pages

1. Откройте Settings репозитория на GitHub.
2. В разделе Pages в пункте Build and deployment выберите ветку `main` и корневую директорию (`/root`).
3. Сохраните изменения. Сайт станет доступен по адресу:
   `https://whywace.github.io/midis-prompt-builder-beta/`
