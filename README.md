# 🎓 MIDIS Prompt Builder

> **Интеллектуальный конструктор персонализированных AI-промптов для студентов Международного института дизайна и сервиса (МИДиС, г. Челябинск).**

Веб-сервис помогает студентам СПО и ВО формировать безупречные, профессионально структурированные промпты для ChatGPT, Claude, DeepSeek, Gemini, Midjourney и других нейросетей с учётом специфики кафедры, курса, дисциплин, дедлайнов и стека технологий.

---

## ✨ Ключевые возможности

- **🎯 24 целевых сценария:**
  - **📚 Учёба и Сессия:** Индивидуальный трек (ИОТ), защита курсовых и ВКР, конспекты по методу Корнелла, интерактивные квизы, экстренная подготовка за 24 часа.
  - **💼 Карьера и Стажировка:** Симулятор собеседований (Mock Interview), аудит переноса навыков, расчет сметы проектов, профильный английский, личный бренд.
  - **🎨 Проекты и Портфолио:** Брейншторм дизайн-концептов, упаковка кейсов для Behance/Dprofile, Customer Journey Map (CJM), UX-копирайтинг, гайдлайны айдентики.
  - **⚡ Hard & Soft Skills:** Глубокий дебаг кода, промпт-инжиниринг для генеративных сетей, код-ревью, фасилитация командной работы в FDE Lab.
- **🏛️ Полная база МИДиС:** Колледж (СПО) и Институт (ВО) — 100% реальных направлений (Дизайн, IT, Гостеприимство, Менеджмент, Лингвистика, Право, Мода).
- **⏱️ Интеллектуальная адаптация:** Автоматическая калибровка этапов под дедлайн пользователя (от 24 часов до 4 лет) и защитный блок от выгорания/прокрастинации.
- **⚡ Чистый стек (Zero Dependencies):** Vanilla JavaScript (ES6+), семантичный HTML5 и чистый CSS3. Никаких тяжелых фреймворков и сборщиков.
- **📱 100% адаптивность:** Безупречная работа на смартфонах, планшетах и десктопах с оптимизированными зонами тапа.
- **📋 Мгновенный экспорт:** Копирование промпта в буфер обмена в один клик и скачивание готового `.md`-файла.

---

## 🚀 Быстрый запуск локально

Проект не требует установки `Node.js`, `npm` или дополнительных пакетов:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-логин>/midis-prompt-builder.git
   ```
2. Откройте файл `index.html` в любом современном браузере (Chrome, Edge, Safari, Firefox).

---

## 🌐 Развёртывание на GitHub Pages

Проект готов к автоматическому развёртыванию:
1. Перейдите в **Settings** вашего репозитория на GitHub.
2. В боковом меню выберите **Pages**.
3. В поле **Source** выберите **GitHub Actions** (или `Deploy from a branch` -> ветка `main` / root).
4. Сервис станет доступен по адресу: `https://<ваш-логин>.github.io/<название-репозитория>/`.
